# Contributing

Prefer a small source-backed correction to a longer unsourced list.

## Add or correct a work

1. Check its DOI, repository identifier or publisher record. Do not add a preprint and its journal version as two independent findings.
2. Preserve title, authors, year, venue, primary source URL and available identifier.
3. Name the evidence type and species or population. Explain why the work is useful in one sentence.
4. Add a specific limitation. Human-cell experiments are not human clinical trials; a clock score is not lifespan.
5. Record what was actually read: record, abstract or full text. Do not upgrade verification by inference.
6. Run the validator and unit tests. Inspect the rendered reading order and bibliography before submitting.

## Scientific and ethical limits

- Link lawful sources rather than copying full texts or gated content.
- Do not add diagnosis, dosing, treatment recommendations or self-experimentation instructions.
- Do not publish participant-level neural, genetic or health data, even if a file looks easy to access.
- Include negative and replication findings. Do not remove a limitation because it weakens a headline.
- For code contributions, reproduce the problem, add a regression test, and state precisely which tests ran. Synthetic data do not establish clinical validity.
- Read the target project's current rules before upstream work, including any restrictions on AI assistance, contributor certifications and required discussion.
